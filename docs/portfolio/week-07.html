Attention evidence dan solution hypothesis

Hasil pengamatan pada 2 kelompok uji coba dari minggu lalu menunjukkan bahwa tingkat kesalahan penamaan versi file berkurang hingga 0%, sementara 4 kelompok lainnya masih mengalami 3 kali salah pengiriman draf. Ketua Kelas menyetujui bahwa masalah kepatuhan format berpengaruh nyata pada efisiensi pengumpulan.

Solution hypothesis: Pembuatan template header draf otomatis dan checklist penyerahan ringkas pada dokumen bersama dapat mencegah tertumpuknya versi file tanpa membebani pengerjaan anggota.

Problem Mechanism Expected benefit Value bagi target (Ketua Kelas)
Versi file berantakan & salah kirim Ringkasan header (Versi, Tanggal, Penulis) di halaman pertama file Anggota kelompok langsung tahu draf mana yang paling mutakhir Beban rekonsiliasi tugas angkatan berkurang
Pengerjaan di jam kritis Checklist 3 poin sebelum export PDF Mengurangi pengiriman draf setengah jadi saat tenggat Mengurangi keterlambatan pengumpulan ke dosen

Pitch dan demonstration

“Berdasarkan uji coba minggu lalu di 2 kelompok, penggunaan format baku berhasil menghilangkan kesalahan salah kirim file secara total. Saya sudah buatkan template dokumen siap pakai dengan header otomatis ini. Demo-nya hanya butuh 1 menit: anggota tinggal isi nama dan versi draf di tabel bagian atas sebelum diunduh. Mari kita uji coba ke seluruh kelompok untuk tugas minggu ini.”

Saya memperagakan penggunaan template dokumen tersebut selama 60 detik kepada Ketua Kelas. Ketua Kelas mencoba mengisi tabel dan merespons: “Tampilannya simpel, tapi gimana kalau anggota kelompok malas mengisi header-nya dan tetap kirim file acak?”

Hidden concern dan adaptation

Awalnya saya mengira kekhawatiran utama Ketua Kelas adalah kompleksitas pembuatan template. Namun, respons tersebut menunjukkan hidden concern sebenarnya: kepraktisan kepatuhan anggota (user compliance).

Adaptasi yang dilakukan: * Memangkas isian header dari 5 baris menjadi hanya 2 baris utama: Nama Penyunting dan Versi/Tanggal. * Menambahkan pengingat otomatis dalam bentuk kalimat petunjuk singkat di bagian atas dokumen.

Ketua Kelas menunjukkan sinyal Interest dengan meminta salinan tautan template yang sudah disederhanakan untuk diperiksa kembali sebelum dibagikan ke grup angkatan.

Evidence, AI, dan feedback

  • Tangkapan layar template dokumen versi awal dan versi setelah disederhanakan berdasarkan masukan.
  • Catatan pengamatan saat sesi demo pitching bersama Ketua Kelas.
  • Penggunaan AI: AI digunakan untuk menganalisis potensi hambatan kepatuhan pengguna (friction points) pada draf template awal. AI tidak digunakan untuk mengambil keputusan penyeragaman format.
